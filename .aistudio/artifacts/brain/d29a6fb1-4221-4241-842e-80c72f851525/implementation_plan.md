# 甜蜜擺鐘甜點塔 (Sweet Swing Stacker)

專為手機直式體驗量身打造的單機日系甜點擺鐘掉落堆疊遊戲。上方擺鐘懸掛精緻日系甜點（舒芙蕾鬆餅、草莓蛋糕、彩色馬卡龍、抹茶千層等），玩家點擊螢幕即時垂直直直釋放掉落；落至頂層時執行精準裁切對齊（超出部分切片滑落），連續完美置中可觸發音階連擊與加分特效，擺鐘維持平穩均勻節奏，全高度保持明亮溫潤的日系天際，掉出邊界或塔身倒塌即結束遊戲。

### User Review & Critical Decisions

> [!IMPORTANT]
> 根據最新需求與實作反饋，本專案落實以下核心規格與優化：

- **視覺風格與主題 (已確認)**：日系可愛甜點食物塔（舒芙蕾鬆餅、草莓鮮奶蛋糕、彩色馬卡龍、抹茶千層、焦糖布丁、生黑巧生乳捲、藍莓塔等，細緻奶油糖霜與水果點綴）。
- **零慣性垂直掉落 (已落實)**：點擊時水平初速歸零（$v_x = 0$），甜點在脫鉤的橫向坐標處**直直垂直落下**，並配備由甜點指向下方塔頂的虛線垂直投影引導線，落點直觀好掌握。
- **無限動態漸層背景（持續平滑漸變，最新更新）**：背景不再於固定層數停止變換，而是採用 8 組高明度日系粉彩主題（香草奶油 ➔ 櫻花粉 ➔ 蜜桃杏 ➔ 若竹抹茶 ➔ 薄荷蘇打 ➔ 蔚藍晴空 ➔ 薰衣草紫 ➔ 金陽舒芙蕾）進行**即時無限連續色彩插值（Smoothstep RGB Lerp）**；背景隨堆疊層數與時間微幅流暢轉化，並伴隨緩緩飄動的半透明砂糖光斑，生動多變且永遠保持高明度高對比，絕不遮掩任何深色甜點。
- **簡約俐落擺鐘美學 (已落實)**：擺鐘維持經典優雅的琥珀木質頂座、金色吊索與掛勾，移除多餘的厚重白色描邊與發光光暈，風格溫潤自然。
- **堆疊與判定機制 (已確認)**：經典精準裁切對齊（Stacker 裁切手感，完美置中全額保留，偏差部分實時切片掉落，剩餘寬度作為下一層基準）。
- **獎勵與反饋機制 (已確認)**：完美正中連擊獎勵（連續 PERFECT 觸發和弦音階升調、甜蜜金光星屑噴發、額外高分與微幅寬度恢復獎勵）。
- **純本地無依賴 Web Audio 音效 (已確認)**：採用瀏覽器原生 Web Audio API 合成日系街機清脆音效（落盤彈跳、切片滑落、連擊升調、失誤音效），支援靜音開關，無需任何外部音訊載入。
- **GitHub Pages 一鍵自動部署 (已支援)**：
  - `vite.config.ts` 設定 `base: './'` 相對路徑，適配任何專案子路徑託管。
  - 內建 `.github/workflows/deploy.yml` 工作流程，推送程式碼至 `main` 分支即自動建置發布至 GitHub Pages，並配置 `--legacy-peer-deps` 確保跨環境建置無阻。

### 1. Overview & Core Concept

- **What It Does**: 玩家掌握頂部擺鐘的擺動節奏，在最合適的時機點擊螢幕，讓甜點精準垂直直落疊在下方的甜點盤或已堆疊的甜點上。未對齊的外緣會被刀鋒般乾淨削切脫落，擺鐘保持均勻節奏；若完全落空或削切後過窄無法立足，塔身崩落結束遊戲。
- **Target Audience / Persona**: 喜愛休閒益智、節奏手感、療癒日系甜點風格與高分挑戰的手機與網頁玩家。
- **Key Value**: 零延遲點擊釋放、紮實無慣性的垂直落體手感、垂直引導輔助線、充滿成就感的 Perfect 連擊音階爬升、手機單手單指直覺暢玩。

### 2. User Experience & Visual Design

#### Key User Flows
1. **Title Screen (遊戲首頁)**：
   - 暖白粉彩的日系甜品店氛圍，中央動態展示輕晃的金色擺鐘與誘人的草莓舒芙蕾示範。
   - 顯示歷史最高層數紀錄（Best Tower）、快速開始按鈕（點擊或按空白鍵）、音效切換鍵與極簡操作提示（「頂部擺鐘載著甜點平穩擺盪，均勻節奏好上手」）。
2. **Playing View (進行中)**：
   - 頂部吊掛擺鐘隨著物理簡諧運動平穩左右擺動，夾帶著隨機輪播的日系精緻甜點。
   - 甜點底部自帶通往下方塔面的**垂直虛線引導線**，輔助預判落點。
   - 玩家點擊螢幕任意處（或鍵盤空白鍵），甜點脫鉤並**直直垂直下墜**（無水平速度漂移）。
   - **裁切與連擊**：
     - 若置中誤差 $\le 4.5\text{px}$：判定「PERFECT!」，金黃星屑粒子散落，音效奏響大調音階（Do-Re-Mi-Fa-Sol-La-Si-Do），連擊數跳動。
     - 若小幅偏差：精準切除邊緣，被切下的邊緣甜點依重力翻轉墜落；基座收縮。
     - 鏡頭隨塔高平滑向上推移，背景漸層隨層數由粉晨、明亮午後、粉紫過渡至高空蔚藍晨曦天際，全程高明度高對比。
   - 頂部 HUD 即時顯示堆疊層數、即時估算高度（例如「約 1.2 m 高」）、Combo 連擊勳章與控制按鈕。
3. **Game Over Modal (結算畫面)**：
   - 甜點落空或塔尖瓦解時，畫面帶有輕微震動回饋與跌落定格。
   - 彈出日式甜品結算卡片，顯示本局堆疊層數、總高度、獲得稱號（例如「甜點初學者」、「舒芙蕾熟練工」、「法式甜點名廚」）、最高紀錄打破提示，以及「再玩一次」即時重新開局。

#### Visual Identity & Theme
- **Color Palette (日系甜點柔和色系)**：
  - 畫布背景：晨曦香草（`#FFFDF8`）➔ 草莓蜜桃（`#FFF5F7`）➔ 薰衣草粉紫（`#FAF5FF`）➔ 蔚藍晨曦（`#E0F2FE` / `#FEF9C3`）。
  - 甜點群：舒芙蕾金黃（`#F6C85F`）、草莓奶霜粉紅白（`#FF6B8B` / `#FFFFFF`）、宇治抹茶綠（`#88B04B`）、黑醋栗馬卡龍紫（`#B39DDB`）、焦糖布丁澄金（`#E67E22`）、生巧克力（`#7D4730`）。
  - UI 介面：深焙咖啡棕（`#3E2723`）高對比字體、無外框乾淨數值、細膩圓角與半透明霧白毛玻璃效果。
- **Typography**: 俐落且具備溫潤感的幾何無襯線字型，得分與層數全面使用 `tabular-nums` 等寬對齊，避免跳動。

### 3. Key Product Decisions & Trade-Offs

- **直落無慣性物理模型 (Direct Vertical Fall)**：
  - *Chosen Approach*: 脫鉤時水平初速度固定為 0 ($v_x = 0$)，僅施加垂直重力加速度。
  - *Why*: 符合玩家直覺——玩家看準置中時機按下，希望物件直接沿著當下的位置掉落，避免擺鐘運動切線慣性導致難以預測的橫向飄移。
- **恆定擺速設計 (Constant Comfortable Swing Speed)**：
  - *Chosen Approach*: 固定角速度 $\omega = 2.5\text{ rad/s}$，不隨堆疊層數暴增。
  - *Why*: 營造專注於精準裁切與連擊節奏的放鬆益智體驗，避免後期速度過快破壞操作反饋。
- **無限動態連續漸層色彩引擎 (Continuous Atmosphere Lerp)**：
  - *Chosen Approach*: 建立 8 組高明度粉彩主題色盤，透過 Smoothstep 與 RGB 線性插值，使背景隨堆疊層數與時間連續流暢變色，並搭配緩慢上升的半透明微型糖霜泡泡。
  - *Why*: 滿足背景不斷變換的需求，且所有色彩區間的明度皆高達 80% 以上，徹底根除深色甜點辨識度不佳的困擾。
- **簡約擺鐘視覺 (Clean Natural Pendulum)**：
  - *Chosen Approach*: 採用原汁原味的細緻木質座與琥珀金鏈條，不使用突兀的厚白描邊與大面積光暈。
  - *Why*: 畫面維持乾淨典雅的日系手繪美感，不產生視覺干擾。
- **Canvas 2D 專屬高效渲染器**：
  - *Chosen Approach*: 使用獨立的 HTML5 Canvas 搭配 `requestAnimationFrame` 與微型粒子系統，完全隔離 React State 重新渲染對遊戲循環的干擾。
  - *Why*: 60FPS 絲滑流暢度，裁切後的碎塊物理計算（切片旋轉、下墜）極其高效，行動裝置發熱量低。
- **GitHub Pages 自動化支援**：
  - *Chosen Approach*: `base: './'` 相對資源路徑搭配 GitHub Actions 官方推薦工作流程。
  - *Why*: 零手動建置麻煩，使用者 git push 即自動上線成公開網址。
