# 甜蜜擺鐘甜點塔 - 丟歪墜落物理與失敗結算動態優化計畫書

本次更新旨在修復「甜點丟歪（完全未疊合）時懸停在半空中」的物理凍結 Bug，並落實玩家確認的「旋轉翻滾墜落出螢幕外」與「墜落離鏡後約 0.8 秒顯示結算視窗」動態節奏。

---

## 使用者確認決策與回饋

> [!IMPORTANT]
> 依據玩家在澄清提問中的選擇：
> 1. **失誤物理動態**：甜點完全丟歪沒有疊上蛋糕塔時，呈現「旋轉翻滾墜落出螢幕外」的自然物理動態。
> 2. **失敗結算節奏**：甜點墜落離鏡後約 0.8 秒平滑展開 Game Over 結算視窗，留給玩家清晰的失敗視覺收尾。

---

## 1. 核心問題剖析與修復方案

### A. 問題根源（Root Cause）
1. 在 `GameCanvas.tsx` 中，當判斷 `overlapWidth <= 0`（完全未接觸塔頂）且無護盾時，程式碼直接設定 `s.gameOver = true`。
2. 由於主迴圈 update 區塊受限於 `if (isPlaying && !s.gameOver)`，一旦 `s.gameOver` 為真，下一幀起該區塊立即停止運算，導致 `s.falling` 的速度與座標更新被強制中斷。
3. 此外，未命中的甜點未被清除（`s.falling = null` 未被呼叫），也未被轉移為不受遊戲結束限制的碎片物件（`s.debris`），導致甜點永久定格在接觸面高度 `targetY`，懸浮在空中。

### B. 解法設計（Tumbling Fall Physics & Failure Flow）
1. **轉化為獨立翻滾物件**：
   - 當判定失誤（`overlapWidth <= 0`）時，依據甜點是偏左或偏右丟歪，給予相應的水平推力（`vx`）與角速度旋轉（`vRot`）：
     - 偏右丟歪：`vx = 70 + Math.random() * 30`, `vRot = 4 + Math.random() * 2`。
     - 偏左丟歪：`vx = -(70 + Math.random() * 30)`, `vRot = -(4 + Math.random() * 2)`。
   - 保留向下的初速度（`vy = s.falling.vy * 0.4`），直接推入 `s.debris` 陣列中。
2. **清除下墜狀態**：
   - 立即清空 `s.falling = null`、`s.isDropping = false`，杜絕靜態渲染殘留。
3. **無障礙自然下墜**：
   - 由於 `s.debris` 的重力、旋轉與鏡頭外清除邏輯獨立於 `!s.gameOver`，甜點物件會在畫面中自然旋轉、加速墜出螢幕底部。
4. **節奏與音效回饋**：
   - 播放失敗聲效與 12px 畫面微震。
   - 設定 800ms 計時器，在甜點完全墜出螢幕後平滑呼叫 `onGameOver` 喚起結算視窗。

## 3. 既有規格完整保留
- **暫停功能**：頂部 HUD 按鈕與鍵盤 `P` / `Escape` 隨時可用。
- **道具系統視覺優化**：
  - **高度提升**：道具高度調高懸浮於蛋糕上方 44px，徹底露出蛋糕表面與下墜路徑。
  - **100% 實心不透明圖標底盤**：圓形底盤全面改為 **100% 不透明純白珍珠底盤（#FFFFFF）**，搭配彩色外框與柔和懸浮陰影，徹底去除半透明問題，圖標與 Emoji 鮮明立體。
  - **圖標右側雙行說明文字**：
    - 解除舊有 localStorage 的永久鎖定，改為每局遊戲各道具首次出現時，必定在**圖標右側**展示 5.5 秒（若靠右緣自動置於左側）。
    - 雙行無背景框精緻排版：第 1 行為道具名稱（道具代表色 + 4px 白描邊），第 2 行為功能簡介（深焙咖啡色 + 3.5px 白描邊），保證清晰且完全不遮蔽下墜對齊線。
- **裁切特效**：精準置中完美判定、連續連擊雙倍 FEVER、奶油果醬碎屑噴濺。
